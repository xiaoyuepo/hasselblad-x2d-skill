# 东方美女复古摄影 Skill / Oriental Beauty Vintage Photography

## 概述 / Overview
本 Skill 专为生成东方美女的复古摄影风格图像，采用哈苏 X2D 系列相机的美学特点。包含详细的正向和反向提示词指南。

This skill is designed to generate vintage photography-style images of Oriental beauties using Hasselblad X2D camera aesthetics. Includes comprehensive positive and negative prompt guides.

## 💡 使用建议 / Usage Tips

1. **模型选择 / Model Selection**
   - 使用专精于逼真人像的模型（如 Deliberate、DreamShaper、Realistic Vision）
   - Use models specialized in realistic portraits

2. **采样步数 / Sampling Steps**
   - 建议 30-50 步以获得最佳质量
   - Recommended 30-50 steps for best quality

3. **CFG Scale**
   - 建议 7-11 之间，平衡创意和准确度
   - Recommended 7-11 for balance between creativity and accuracy

4. **分辨率 / Resolution**
   - 建议 768×1024 或 512×768 用于竖幅肖像
   - Recommended 768×1024 or 512×768 for portrait orientation

5. **微调 / Fine-tuning**
   - 根据需要调整提示词中的服装、背景和风格元素
   - Adjust clothing, background, and style elements as needed

6. **多次生成 / Multiple Generations**
   - 生成多张图像以获得最佳效果
   - Generate multiple images to find the best results
